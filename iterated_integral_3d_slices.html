Order 1  (integrate y first, then x):

  ∬_R 6(x - y) dA
    = ∫₀¹ [ ∫₀ˣ 6(x - y) dy ] dx
    = ∫₀¹ [ 6xy - 3y² ]₀ˣ dx
    = ∫₀¹ 3x² dx
    = 1

Each slab in Order 1 is perpendicular to the x-axis. At x = x*, the
cross-section is a right triangle in (y, z) with vertices
  (0, 0), (x*, 0), (0, 6x*)
so its area is ½ · x* · 6x* = 3x* — exactly the inner integral.


Order 2  (integrate x first, then y):

  ∬_R 6(x - y) dA
    = ∫₀¹ [ ∫_y¹ 6(x - y) dx ] dy
    = ∫₀¹ [ 3x² - 6yx ]_y¹ dy
    = ∫₀¹ ( 3 - 6y + 3y² ) dy
    = 1

Each slab in Order 2 is perpendicular to the y-axis. At y = y*, the
cross-section is a right triangle in (x, z) with vertices
  (y*, 0), (1, 0), (1, 6(1 - y*))
so its area is ½ · (1 - y*) · 6(1 - y*) = 3(1 - y*)² = 3 - 6y* + 3y*².

Both integration orders give the same answer (1), as Fubini's theorem
guarantees for a continuous integrand on a closed bounded region.
