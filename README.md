# Teaching applets

Interactive applets for exploring mathematical and statistical concepts.

| Applet | Explore |
| --- | --- |
| [ANOVA explorer](anova-explorer.html) | Adjust group means and shared variance to explore between-group and residual variation, the F statistic and its p-value. |
| [Least-squares plane](least-squares-plane.html) | Adjust a regression plane, inspect residuals and compare the residual sum of squares with the least-squares solution. |
| [Iterated integral with 3D slices](iterated_integral_3d_slices.html) | Explore both integration orders over a triangular region using cross-sections and slabs. |
| [Double integral as a Riemann sum](riemann_double_integral.html) | Vary subdivisions and sample points to approximate a double integral with rectangular prisms. |

## Running the applets

Download the files and open any HTML file in a modern browser. No build step is required.

The two integration applets load Three.js from cdnjs and require internet access and WebGL support. The ANOVA and least-squares applets are self-contained.
